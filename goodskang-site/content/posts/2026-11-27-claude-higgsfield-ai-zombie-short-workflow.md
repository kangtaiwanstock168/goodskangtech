這支 30 秒的打殭屍短片，主角庭安是 AI 角色，畫面全部是 AI 生成的。阿康 0 程式基礎，做法只有一個：在 Claude 加上 Higgsfield 連接器，然後打字跟 Claude 講要什麼。

先講清楚，沒有那麼無腦。畫面改了 28 版才過關，臉會跑掉、動作接不起來，光一個關門就重做三次。這些坑阿康都踩完了，下面照順序寫給你。

## 先看花了多少

這個數字要先讓你知道，再決定要不要玩。

| 項目 | 數字 |
|---|---|
| 成品長度 | 約 30 秒，直式 9:16 |
| 畫面版本 | 28 版 |
| 11/26 當天 Seedance 2.5 扣點 | 4,124 點（已扣掉退款） |
| 換算台幣 | 約 NT$6,400 |

換算方式：阿康加購 2,000 點花 NT$3,112，等於一點約 NT$1.556。

這 4,124 點大部分不是花在成品上，是花在重做。前面幾版一口氣生整段、沒先鎖角色、沒先畫分鏡，錯一個地方就整段重來。照這篇的順序做，你不會需要花到這麼多。

## 要準備什麼

1. **Claude 帳號**。免費版也能加自訂連接器，但只能加一個，出處是 [Claude 官方說明](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)。
2. **Higgsfield 帳號**。從這裡申辦：[Higgsfield 官網](https://higgsfield.ai?fpr=larson-d154f5)。每一次生成都會扣 Higgsfield 點數，方案和價格常常在變，以官網當下顯示的為準。
3. **一台能開瀏覽器的電腦**。不用裝任何程式。

## 把 Higgsfield 接進 Claude

Higgsfield 官網的安裝說明就是兩步：登入 Claude，新增連接器後登入 Higgsfield。

```steps
🌐 打開 Claude，登入你的帳號
➕ 到連接器設定，按「Add custom connector」（新增自訂連接器）
📋 名稱填 Higgsfield，網址貼上下面那一行
🔑 按「Continue」，跳出 Higgsfield 登入頁，登入並同意授權
✅ 回到 Claude 對話，打「幫我查 Higgsfield 還剩多少點數」，有回數字就是接好了
```

## 六關流程

順序很重要。前三關幾乎不花點數，錢都花在第四關，所以前三關沒過不要往下走。

| 關卡 | 做什麼 | 過關標準 |
|---|---|---|
| 1 定故事 | 一句話講完：誰、要幹嘛、輸了會怎樣 | 講給朋友聽，他聽得懂在緊張什麼 |
| 2 鎖角色 | 生一張角色設定圖 | 臉、髮型、衣服你都滿意，之後不再改 |
| 3 畫分鏡 | 每一鏡的鏡位、動作、秒數 | 一格一格看下來，動作接得起來 |
| 4 逐鏡生成 | 一次只生一鏡，每鏡都附角色圖 | 逐格看，臉沒跑、道具沒消失 |
| 5 接起來審片 | 照分鏡順序接成一支 | 上一鏡結尾的姿勢＝下一鏡開頭的姿勢 |
| 6 配聲音 | 先用生成時自帶的聲音 | 沒有電玩感的音效，腳步對得到腳 |

## 第 2 關：角色設定圖

這張圖是整支片的地基。阿康用的是這一張：全身正面、全身側面、兩張臉部特寫，白底。

![庭安的角色設定圖：全身正面、側面，加兩張臉部特寫](/img/tingan-character-sheet.jpg)

指令直接複製，括號裡換成你的角色：

```
幫我用 Higgsfield 生一張角色設定圖，橫式 16:9，純白背景。
角色：（年齡、長相、髮型、服裝、手上拿的東西）
版面：左邊全身正面站姿，中間全身側面站姿，右邊上下兩張臉部特寫（正面、微側）。
四個畫面要是同一個人、同一套衣服。
先告訴我這張要扣多少點數，我說好再生。
```

生出來不滿意就在這一關改到滿意。這一關一張圖只要幾點，後面影片一鏡動輒二、三十點起跳。

## 第 3 關：分鏡

```
我要做一支 30 秒、直式 9:16 的短片。
故事：（一句話）
先不要生影片。幫我畫 8 到 10 格分鏡故事板，每一格寫：
1. 鏡頭放在哪裡、往哪裡拍
2. 角色在畫面左邊還是右邊、面向哪裡
3. 這一鏡開始和結束時，角色的姿勢和手上的東西
4. 秒數
我確認後才往下。
```

第 3 點最重要。阿康被退最多次的，都是上一鏡和下一鏡的姿勢對不起來。

## 第 4 關：逐鏡生成

```
照第 N 格分鏡生成影片，模型用 Seedance 2.5，直式 9:16，先用 720p。
一定要附上角色設定圖當參考。
這一鏡開頭的姿勢：（照抄上一鏡的結尾）
這一鏡結尾的姿勢：（照抄分鏡）
手上的（道具）全程握著，不能掉、不能消失。
先告訴我這一鏡要扣多少點數，我說好再生。
生完把影片每半秒抽一格排成一張圖給我看，
並告訴我臉有沒有跑掉、道具有沒有消失、動作有沒有接上一鏡。
有問題先告訴我，不要自己重生。
```

要把一鏡往後延伸、接續動作時，多加這一句：

```
延伸上一鏡時，一樣要附臉部特寫和角色設定圖，不能只丟影片給它接。
```

## 第 5、6 關：審片和聲音

```
把目前過關的鏡頭照分鏡順序接起來，不要動已經過關的鏡頭。
接好後檢查每一個剪接點：前一格和後一格，角色的位置、姿勢、手上的東西是不是一樣。
列一張表給我：第幾秒、哪裡對不上。
```

```
聲音先用每一鏡生成時自帶的。
要另外加音效時，只用真實錄音的音效，不要合成的電玩音效。
腳步聲要對到腳落地的那一格。
```

## 踩過的 8 個坑

### 1. 沒附臉部參考，延伸出來變成另一個人

阿康有一鏡用「延伸影片」接續動作，只丟了影片沒附角色圖，生出來的臉直接換成另一個人。延伸、接續、改畫面，每一次都要附角色設定圖和臉部特寫。

### 2. 一口氣生整段，錯一個地方整段重來

早期一次生 10 幾秒，一鏡就要一、兩百點，裡面只要有一秒不對就全部作廢。改成一鏡 3 到 5 秒、一次只生一鏡之後，重做的成本才降下來。

### 3. 上一鏡被抓起來，下一鏡站在地上

大殭屍把主角抓離地面，下一鏡她卻好好站著。解法是分鏡就先寫死每一鏡結尾的姿勢，生成時照抄到下一鏡的開頭。

### 4. 手上的球棒掉了，下一鏡又出現

AI 很愛讓道具自己消失或掉在地上。指令裡要明寫「全程握著，不能掉」。

### 5. 關門一鏡到底，時間和距離永遠對不上

殭屍明明已經跑到門口，下一格門就關好了，看起來很假。最後拆成三鏡才過關：

![關門拆成三鏡：倉庫內遠景、從門口往內拍、低角度拍門落地](/img/tingan-zombie-door-3shots.jpg)

1. 倉庫內遠景：主角跑進來，殭屍還在遠處。
2. 從門口往內拍：鐵捲門從畫面上方降下來，主角轉身備戰。
3. 低角度特寫：門落地，門縫外只剩殭屍的腳。

時間和距離對不上的動作，不要硬塞在一鏡裡，拆開讓剪接幫你。

### 6. 參考圖裡有門，AI 就把門畫到主角背後

要拍「從門口往內看」的反方向鏡頭時，阿康附了原本那張有鐵捲門的倉庫圖，結果 AI 把門畫到主角後面，兩次共 56 點白花。反方向的鏡頭不要附原方向的場景圖，改用文字寫清楚鏡頭站在哪裡、往哪裡拍。

### 7. 音效聽起來像電玩

外加的合成音效一聽就出戲。開頭殭屍的呻吟用的是生成時自帶的聲音，反而最自然。小殭屍敲門就是輕輕敲，不用轟隆巨響。

### 8. AI 說沒問題，不等於沒問題

請 AI 幫忙審片可以抓到一部分，但阿康有一次沒理會它提的「腳在門口滑」，結果那正好是被退的地方。反過來它說沒問題的地方也漏過。最後一定要自己一格一格看。

## 常見問題

### Q1. 一定要付費才能玩嗎？

Claude 免費版可以加一個自訂連接器。Higgsfield 這邊每次生成都扣點數，方案內容以 [Higgsfield 官網](https://higgsfield.ai?fpr=larson-d154f5) 當下的說明為準。

### Q2. 第一次玩，點數大概抓多少？

先只做前三關：角色設定圖和分鏡故事板，一張圖只要幾點。確定角色和分鏡都滿意了，再照一鏡一鏡的方式生影片。阿康這支多花的點數，幾乎都是跳過前三關造成的。

### Q3. 為什麼先用 720p？

草稿用 720p 比較省。整支畫面都過關之後，再請 Claude 把過關的鏡頭升到 1080p。

### Q4. 指令一定要用中文嗎？

阿康全程用中文跟 Claude 講，Claude 會自己轉成模型看得懂的寫法。你只要把鏡頭位置、角色姿勢、手上的東西講清楚。
